How it works

From blank template to downloadable résumé in a few minutes.

1

Pick a template

Choose a layout and starting color theme from the gallery above.

2

Edit inline

Click ✏️ Edit and type directly on the résumé — no forms or JSON to fill out.

3

Customize freely

Add/remove experience, skills, and bullets. Switch themes, fonts, and layout anytime.

4

Export

Save a self-contained HTML file, or export directly to a one-page PDF.

Why this résumé builder?

🔒

Privacy-first

Everything runs client-side. Your draft is stored only in your browser's local storage — never uploaded anywhere.

🎨

14 themes · 15 fonts

Mix and match color palettes and font stacks with any of the layout templates.

📏

One-page fit gauge

A live meter shows how full your page is, so your résumé stays print-ready on a single A4 page.

💾

Portable HTML export

Download a fully self-contained HTML file you can reopen, keep editing, or send to anyone.

🖨️

Clean PDF export

Uses your browser's native print dialog for crisp, one-page PDF output — no plugins required.

🧩

No dependencies

Pure HTML/CSS/JS. Works offline, forkable, and easy to self-host or customize.
